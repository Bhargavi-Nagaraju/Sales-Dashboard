# Sales Performance Dashboard using Excel, SQL & Power BI

This project showcases an end-to-end sales analysis to derive meaningful business insights using Excel, SQL Server, and Power BI. The project focuses on data cleaning, SQL-based analysis, and interactive dashboard creation for better business decision-making.

## Project Workflow

### 1. Data Preparation (Excel)
- Cleaned and validated raw sales data.
- Removed inconsistencies and ensured data accuracy for analysis.

### 2. SQL Processing (SQL Server - SSMS)
- Imported the  cleaned dataset into SQL Server.
- Wrote SQL queries to analyze:
  - Total Sales
  - Profit Analysis
  - Regional Performance
  - Customer Segments
  - Product Category Trends

### 3. Dashboard Development (Power BI)
- Connected Power BI with SQL Server.
- Built an interactive sales dashboard to visualize key business insights and trends.

## Key Insights
- **Top Performing Region:** West  
- **Top Product Category:** Technology  
- **Sales Growth:** Significant increase observed between **2015–2017**  
- **Top Customer Segment:** Consumer (**50.5% contribution**)  

## Technologies Used
- Microsoft Excel  
- SQL Server (SSMS)  
- Power BI  

## Project Outcome
This project helped in understanding the complete data analysis workflow, including data cleaning, SQL querying, and dashboard development for business intelligence.
